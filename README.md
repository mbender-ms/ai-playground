# ai-playground

A personal sandbox for building and testing AI skills, agents, workflows, and related tooling
before any of it is promoted to a production repository.

## Disclaimer

> **Everything in this repository is pre-production, experimental, and test in nature.**
> Nothing here is supported, maintained, or guaranteed to work. Use at your own risk.
> Opinions and code are my own and do not represent my employer.

## Repository structure

| Folder | Purpose |
| --- | --- |
| [agents](agents/) | Agent definitions and custom chat modes. |
| [skills](skills/) | Skill packages (`SKILL.md` plus supporting files). |
| [workflows](workflows/) | Multi-step and orchestrated processes that chain skills or agents. |
| [tools](tools/) | Scripts, MCP servers, and helper utilities. |
| [experiments](experiments/) | Throwaway spikes and one-off tests. Output is not committed. |
