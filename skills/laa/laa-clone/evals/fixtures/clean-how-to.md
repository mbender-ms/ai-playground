# Configure a sample endpoint

Configure a sample endpoint in the Azure portal and verify that it accepts requests.

## Prerequisites

- An Azure subscription.
- An existing example resource.

## Configure the endpoint

1. In the Azure portal, open your example resource.
1. Under **Settings**, select **Endpoints**.
1. Select **Add**, enter a unique endpoint name, and then select **Save**.

## Verify the endpoint

Confirm that the endpoint appears with a status of **Ready**.
